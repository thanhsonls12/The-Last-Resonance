# The Last Resonance UI icons

Vector UI icons for Android landscape screens and desktop.

## Palette

- Cyan: `#14C7FF` — primary action, active, selected.
- Orange: `#FF6114` — danger, restart, quit, mechanism action.
- Purple: `#B66CFF` — memory and energy systems.
- Slate: `#7E8CA8` — locked or disabled state.
